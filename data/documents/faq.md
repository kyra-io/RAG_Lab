# Frequently Asked Questions

## How often are database backups performed?

Acme Database performs automatic backups every 24 hours.

## Which Git providers are supported by Acme Deploy?

Acme Deploy currently supports GitHub and GitLab repositories.

## Can Acme Compute restart failed applications?

Yes. Acme Compute automatically monitors applications and restarts them when a failure is detected.

## Where is Acme Cloud headquartered?

Acme Cloud is headquartered in Lisbon, Portugal.

## Which pricing plans are available?

Acme Cloud offers three pricing plans: Starter, Professional, and Enterprise.

## Does Acme Cloud manage database servers?

Yes. Acme Database is a managed PostgreSQL service, so customers do not need to manage database servers or operating system updates themselves.

## Which regions are supported?

Acme Cloud is available in Europe, North America, and Asia Pacific.
