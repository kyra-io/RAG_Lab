# Acme Cloud Products

Acme Cloud provides several products for software development teams.

## Acme Compute

Acme Compute is a managed compute platform for running web applications, APIs, and background workers.

Applications deployed on Acme Compute are automatically monitored and restarted when a failure is detected.

## Acme Database

Acme Database is a managed PostgreSQL database service.

Customers do not need to manage database servers, operating system updates, or database backups manually.

Automatic backups are performed every 24 hours.

## Acme Storage

Acme Storage is an object storage service designed for files, images, videos, and application assets.

Objects can be accessed through the Acme Cloud API.

## Acme Deploy

Acme Deploy is a continuous deployment tool.

It can automatically deploy an application when a new version is pushed to a connected Git repository.

Acme Deploy supports GitHub and GitLab repositories.

Deployments can be configured to run automatically after every push or manually through the Acme Cloud dashboard.
